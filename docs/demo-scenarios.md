# Demo Scenarios

## Happy Paths

1. `How many absences did Sara Bennani have between 2026-01-01 and 2026-03-31?`
2. `How many sick leaves did Sara Bennani have in Q1 2026?`
3. `List Sara Bennani's absences in March 2026.`
4. `How many absences did my direct report Ahmed have last month?`
5. `Show the absence breakdown by type for Yasmine in February 2026.`

## Failure Paths

1. Manager asks about `Karim Ouali` and receives a forbidden response.
2. HR admin asks about `Yasmine` and receives a clarification request because two authorized matches exist.
3. User asks a payroll question and receives the safe unsupported-intent fallback.
